# packages/ui — Design System

## Rules
- theme/ — Primitive + semantic tokens in oklch. Single source of truth.
- web/ — HeroUI v3 component wrappers for Next.js.
- native/ — HeroUI Native component wrappers for Expo.
- Compound component pattern (dot notation) for all custom compositions.
- Semantic variants only (primary, secondary, danger, ghost, outline).
- Three-layer hierarchy: primitive → semantic → component tokens.
- 4px base grid: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128.
- Light + dark modes via CSS custom properties.
