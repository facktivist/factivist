# apps/web — Next.js + HeroUI

## Commands
- Dev: `bun run dev` | Build: `bun run build`
- Test: `bun run test` | E2E: `bun run test:e2e`

## Rules
- App Router only. No pages/ directory.
- Server Components by default. "use client" only for interactivity.
- Async data fetching in plain functions, not components (for Vitest testability).
- HeroUI compound components via dot notation. Semantic variants only.
- Turbopack bundler (built-in, no config).
- Playwright for E2E in `e2e/`. Vitest + Testing Library in `__tests__/`.
